# 校园二手交易平台 · 电脑端 (PC Web)

> 本工程基于原老旧微信小程序（2018年开源）的核心业务逻辑进行**完整逆向工程与现代化桌面端重构**。
> 采用 **Vue 3 + Vite 5 + Element Plus + Pinia + Vue Router** 构建，彻底解决了原移动端布局狭窄、代码老化、依赖失效的局限性，并实现了面向大屏电脑端的全新高颜值体验。

---

## 一、系统亮点与逆向重构特性

1. **纯静态运行 & 100% 兼容 GitHub Pages**：
   - 采用 `base: './'` 相对路径与 Hash 路由模式（`createWebHashHistory`），打包后的产物可直接部署于任意 GitHub Pages、Gitee Pages 或静态服务器，刷新页面零 404！
2. **免后端与数据库依赖（内置响应式 LocalStorage 引擎）**：
   - 原项目依赖的私网 PHP 接口（`192.168.0.111`）已完全不可访问。本电脑端内置一套完整的本地数据持久化仓储引擎，预置 20+ 条真实高质量的教材、闲置物品、兼职岗位、跑马灯资讯等数据。
   - 所有新增发布、删除下架、加购物车、预约下单等操作均能实时响应并持久化保存在浏览器中，支持一键“重置演示数据”。
3. **补齐原小程序半成品与缺失流程**：
   - 完善了原小程序中仅有空模板的“预约订单结算”与“订单列表管理”闭环，实现了完整的线上选购预约、约定面交时间地点、订单状态流转。
4. **大屏桌面级 UI 视觉提升**：
   - 基于 Element Plus 深度定制校园经典蓝主题（`#1E68C9`），配备顶部校区切换（咸安校区 / 温泉校区）、实时校园天气气象、全宽轮播图、校园头条播报、多条件复合筛选器等。

## 三、快速开始

### 1. 安装依赖
```bash
cd pc-web
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
启动成功后，浏览器访问控制台提示的地址（如：`http://localhost:3000/#/`）。

### 3. 构建发布产物 (供 GitHub Pages 部署)
```bash
npm run build
```
执行完成后，打包生成的静态文件位于 `pc-web/dist` 目录下。

---

## 四、GitHub Pages 部署指南

只需将 `pc-web/dist` 目录下的内容推送到仓库的 `gh-pages` 分支（或仓库根目录的 `docs/` 文件夹）：

### 简易推送方法：
```bash
# 1. 编译打包
npm run build

# 2. 进入打包目录直接部署至 gh-pages 分支
cd dist
git init
git add -A
git commit -m "deploy: deploy pc-web to github pages"
git branch -M gh-pages
# 替换为您的 GitHub 仓库地址
git remote add origin https://github.com/<您的用户名>/<您的仓库名>.git
git push -f origin gh-pages
```

随后在 GitHub 仓库的 **Settings -> Pages** 中，将 Source 设置为 `Deploy from a branch` 并选择 `gh-pages` 分支即可在线访问！

## 五、系统核心业务功能矩阵

- **门户首页**：大屏轮播、校园头条滚屏、校区天气、四大分类金刚区、今日好书与闲置推荐、热门兼职速递。
- **二手书城**：多条件复合筛选（校区、成色、专业资料/教材）、多字段搜索、综合排序。
- **闲置杂货**：数码配件、宿舍小家电、单车等闲置物品网格流与成色筛选。
- **校园兼职**：勤工助学、图书馆管理员、家教等职位卡片与联系方式一键复制。
- **详情页**：高清实物预览、成色及出版参数、卖家学生认证掩码、一键加入购物车、发起当面验货预约。
- **购物车与结算中心**：图书与物品分类结算、全选计算总额、自提地点/时间预约单生成。
- **三合一发布中心**：支持本地图片实时 Base64 预览、表单校验、发布二手图书/闲置/兼职。
- **学生中心**：我的发布管理（支持下架与删除）、我的预约订单（待面交/已完成）、寝室自提地址配置。
